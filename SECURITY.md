# Security

Please report a vulnerability in Toft privately, by email to
**security@gettoft.com**, and never in a public issue or discussion.

Include what you found, the version (`toft version`, or System info in the
admin pages), and the steps that show it. You will get an answer within a few
working days, and a fix is announced in the release notes once it ships.

Toft is free, and has no bug bounty.
